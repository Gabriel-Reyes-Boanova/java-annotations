## 📚 O que estou estudando

### 🍃 Ambiente Spring

Explorando o ambiente Spring, entendendo sua organização e aprendendo a desenvolver aplicações de forma estruturada.

* 📌 **Fundamentos:** Inversão de Controle (IoC) e Injeção de Dependências.
* 🛡️ **Spring Security:** Autenticação, autorização, controle de acesso e segurança com JWT.
* 🧪 **Spring Validation:** Validação de payloads e DTOs utilizando Bean Validation (`@NotNull`, `@Size`).
* ⚙️ **Desenvolvimento:** Criação de APIs REST estruturadas e manipulação de requisições HTTP.
* 🧩 **Aplicação Prática:** Conectar conceitos teóricos a cenários reais de microsserviços e APIs.

### ☕ Funcionalidades e recursos do Java
